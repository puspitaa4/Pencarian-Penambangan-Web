# PPW (Pencarian & penambangan Web)

Pengertian Web Mining

Web Mining adalah proses menemukan, mengambil, dan menganalisis informasi atau pola yang berguna dari data yang terdapat di dalam World Wide Web.

Web Mining merupakan penerapan konsep Data Mining pada sumber data berbasis web. Data yang dapat dianalisis tidak hanya berupa teks, tetapi juga dapat berupa gambar, video, hyperlink, serta aktivitas pengguna pada suatu website.

Tujuan utama Web Mining adalah memperoleh informasi dan pengetahuan yang dapat digunakan untuk membantu pengambilan keputusan.
